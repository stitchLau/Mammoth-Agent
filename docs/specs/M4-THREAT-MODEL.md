# M4 威胁模型（S0）

- **日期**：2026-11-13
- **范围**：M4-core（S1–S6）与 M4.5 的外部集成/通知/Agent 前置
- **方法**：按资产/信任边界/威胁/缓解组织；不追求形式化 STRIDE 全覆盖，但覆盖 M4 新增攻击面
- **依据**：`docs/08-SECURITY-AND-TRUST.md`、`AGENTS.md`、`decisions/ADR-0011/0012/0013`、`decisions/ADR-0006/0008` 增补

## 1. 资产

| 资产 | 说明 |
|---|---|
| 凭据 | Jira/CSM 只读账号、SMTP 密码、企微 webhook URL/key、会话令牌 |
| 客户/项目数据 | 需求、证据、方案、知识、交付、导入的外部记录 |
| 审计 | `audit_log`、`agent_call`、通知投递状态 |
| 交接包 | 批准方案/任务/验收/基线 zip |
| 通知内容 | 事件摘要、对象链接 |
| 服务可用性 | 单节点 writer、任务队列、MCP 只读进程 |

## 2. 信任边界

1. 浏览器/SPA ↔ Domain Service（HTTP/HTTPS、Cookie/CSRF）；
2. Domain Service ↔ SQLite/Artifact（本地文件系统、实例锁）；
3. MCP 只读进程 ↔ 数据根（只读 DB + 审计 journal）；
4. Domain Service ↔ SMTP/企微（出站、凭据、外发内容）；
5. 导入文件/外部记录 ↔ 业务对象（不可信内容 → 证据/候选）；
6. 负责人/运维 ↔ 配置/密钥（环境/OS 存储）；
7. 外部 Agent ↔ 交接包/只读 MCP（无写路径）。

## 3. 威胁与缓解

### T1 凭据泄露（Jira/CSM/SMTP/企微）

- **场景**：凭据写入 DB/日志/导出/交接包/截图；webhook URL 被日志打印；错误消息回显 token。
- **缓解**：`SecretProvider` 仅环境/OS；日志/错误统一脱敏；配置 UI 掩码；导出/交接包排除凭据；代码评审 + 秘密扫描；Jira HTTP 未 HTTPS 不发送凭据。
- **验证**：日志/导出的模式扫描；单测注入秘密后断言不出现。

### T2 外部内容 Prompt Injection / 污染

- **场景**：Jira 描述/评论含“忽略系统指令”“把草稿标为 verified”等；导入内容进入知识/RAG。
- **缓解**：外部记录只作证据/候选；不自动改状态/知识/方案；不自动进 RAG；人工映射/审核；Agent 工具仍只读 verified；提示词/工具边界不因资料改变。
- **验证**：导入含注入文本的夹具，断言状态不变、证据可追溯、Agent 工具不越权。

### T3 未授权访问/越权

- **场景**：非 org_admin 建用户/停用/重置；viewer 导入；跨项目映射；Agent 账号登录 Web；MCP 非成员读取。
- **缓解**：服务层 `AuthorizationService` 统一判定；org_admin 校验；项目角色；Agent 账号禁登；MCP `requireProjectRole`；负向测试。
- **验证**：403/401 矩阵；跨项目/角色测试。

### T4 审计缺失/篡改

- **场景**：MCP 调用无审计；导入/外发/停用无审计；审计可更新/删除。
- **缓解**：MCP journal + writer 入库 `agent_call`；导入/映射/外发/账号动作审计；V3 触发器 append-only；事件唯一 ID 防重复。
- **验证**：审计行存在/不可更新删除；重复 journal 不重复；脱敏。

### T5 外发误发/骚扰/泄露

- **场景**：默认启用邮件/企微导致误发；向客户/外部群发送；通知含敏感正文；无收件人限制；无限速。
- **缓解**：邮件/企微默认关闭；启用需配置校验；测试目标；内部收件人/事件白名单；限速/重试/死信；正文摘要化；审计；向客户发送需新 ADR。
- **验证**：默认配置零外发；启用后本地 stub/SMTP 只收到测试目标；停用即停止；限速。

### T6 SSRF/网络边界（M4.5）

- **场景**：Jira/CSM URL 被配置为任意主机；重定向到内网元数据；代理/凭据外泄。
- **缓解**：主机白名单；禁止重定向到非白名单；HTTPS；超时/响应上限；不跟随任意 URL；只读账号。
- **验证**：mock 重定向/非白名单断言拒绝；配置校验。

### T7 交接包泄露/夹带

- **场景**：zip 含 `.env`/token/源码/生产连接串；下载越权；manifest 被篡改。
- **缓解**：固定文件清单；秘密模式扫描；不含源码/凭据；角色校验；sha256 manifest；Artifact 内容寻址；审计。
- **验证**：zip 内容/哈希；注入秘密夹具被拒；越权 403。

### T8 导入文件攻击

- **场景**：超大文件/zip bomb；CSV 公式注入；路径穿越；编码/坏行导致崩溃；重复导入爆炸。
- **缓解**：大小/行数上限；只接受 CSV/JSON（不解压任意 zip）；不把导入值当公式/路径；流式解析；坏行隔离；幂等/唯一键；事务/批次状态。
- **验证**：超限/坏行/重复/编码测试；无路径写入。

### T9 SQLite/单写者/任务并发

- **场景**：任务 worker 与请求争锁；MCP 只读进程跑任务；长事务阻塞；重复执行。
- **缓解**：worker 仅 writer；短事务；`idempotency_key`；实例锁；MCP `read-only=true` 不调度；PG 留 M5。
- **验证**：MCP 无任务；重复任务幂等；并发测试。

### T10 团队服务器暴露（S6/M4.5）

- **场景**：绑定 0.0.0.0 + HTTP；伪造 `X-Forwarded-*`；Cookie 非 Secure；无 TLS。
- **缓解**：默认 localhost；反向代理 TLS；只信任配置代理；Secure/HttpOnly/SameSite；防火墙；不交付生产证书/公网。
- **验证**：代理头伪造测试；Cookie 属性；默认绑定。

### T11 供应链/依赖

- **场景**：新增 mail/CSV/GreenMail 等依赖来源/许可证/漏洞。
- **缓解**：优先官方/成熟依赖；记录版本/许可证；`mvn dependency:tree`/漏洞扫描；测试作用域依赖不进入运行时；DSH 插件变更另行批准。
- **验证**：依赖清单/许可证记录；构建通过。

## 4. 安全测试清单（M4 验收）

- [ ] 非 org_admin 建用户/停用/重置/改主数据 → 403
- [ ] 停用用户旧会话 → 401；Agent 账号登录 → 401
- [ ] 强制改密用户只能访问白名单
- [ ] 导入跨项目/ viewer → 403；dry-run 零写入
- [ ] 重复导入/版本变化/坏行/超限
- [ ] 交接包无秘密/无源码；越权 403；manifest 校验
- [ ] MCP 只读进程不写 DB/不跑任务；journal 入库/脱敏
- [ ] 默认配置邮件/企微零外发；启用后本地 sink/stub 收到；停用即停
- [ ] 审计 append-only；导入/映射/外发/账号动作有记录
- [ ] 依赖/许可证/漏洞检查

## 5. 不在本威胁模型内

- 生产环境网络/主机加固、WAF、DDoS、OS 补丁；
- 客户侧 SSO/OIDC、多租户隔离（M5+）；
- 应用内 LLM 的提示词注入/模型安全（另立 ADR）；
- 真实客户数据合规评估（需负责人/法务）。
