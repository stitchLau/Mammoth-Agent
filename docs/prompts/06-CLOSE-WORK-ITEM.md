# Prompt 06 — 工作项结项与知识更新提议

针对【WorkItem ID】开展结项分析。此阶段默认只生成分析和更新提案，不直接发布正式知识。

读取 Approved Design、开发任务、实施记录、Git Commit/diff、测试结果和人工反馈。

对每个业务/技术设计项判断：符合、偏离、额外实现、未实现、客户变更、技术替代、缺陷修复或无法验证。每项结论给出证据。

生成：
1. 原方案与实际实施差异矩阵；
2. 未完成项和残余风险；
3. 业务最终交付文档草案；
4. 技术 As-built 文档草案；
5. 项目知识更新提案（文档、段落、来源、版本）；
6. 可以抽象为产品级/通用经验的候选知识，并标明脱敏与授权审查要求。

不得覆盖 Approved Design，不得把 AI 推断标记为 verified。待负责人确认后才进入发布/结项。
