# Prompt 05 — 会话交接与上下文压缩

当前会话准备结束/上下文即将不足。请不要继续扩大工作范围。

1. 检查 Git 状态和当前 Commit；
2. 总结已确认事实，区分假设和待确认事项；
3. 列出改动文件与每个文件的意图；
4. 列出实际运行的命令及完整结果摘要；
5. 记录失败测试和未解决问题；
6. 记录产品/架构决策及需要更新的 ADR；
7. 给出下一会话唯一最优先的最小行动；
8. 明确新会话必须先读哪些文件；
9. 按 `docs/templates/SESSION-HANDOFF.md` 更新交接记录。

不要写“继续之前的工作”这种依赖聊天历史的表述。交接必须让一个全新 Agent 会话在不读取旧对话的情况下恢复工作。
