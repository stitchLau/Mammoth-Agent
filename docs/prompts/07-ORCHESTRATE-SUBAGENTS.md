## 执行要求

1. 判断本任务是否值得委派；如不值得，说明原因并由你直接完成。
2. 如果委派，选择最少且足够的角色，不为使用多 Agent 而使用多 Agent。
3. 为每个子 Agent 提供自包含 prompt，必须包含角色职责、背景、输入、问题清单、读写权限、禁止事项、输出格式和完成定义。
4. Fresh 子 Agent 不得依赖主会话未写入 prompt 的历史内容。
5. 只读调查可以并行；写入任务先确定独立 Worktree 和文件边界。
6. 不允许多个 Agent 未经隔离同时修改同一文件、模块、迁移或公共契约。
7. 收到结果后检查证据和版本，识别分歧，不以多数票代替验证。
8. 你必须独立整合结果并对最终计划/实现负责。
9. 产品、架构、安全、数据和范围决策需要负责人确认。
10. 输出子任务分配表、委派方式、结果摘要、未解决冲突和下一步。

本轮是否允许写入：【只读 / 明确授权的文件范围】

## 完成定义

- 委派任务边界明确；
- 子 Agent 输出可追溯；
- 冲突得到处理或明确保留；
- 没有未经批准的文件写入和架构决策；
- Lead 输出唯一的综合结论。
