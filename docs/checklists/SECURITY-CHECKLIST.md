# Security Checklist

- [ ] 当前工作区不包含生产凭据或未经授权的客户数据
- [ ] `.env`、token、私钥、证书、数据库转储已排除 Git
- [ ] API 服务端执行权限检查，不依赖 UI 隐藏
- [ ] 检索前进行客户/项目权限过滤
- [ ] Agent Tool 有明确权限、输入校验、输出约束、审计和超时
- [ ] 客户附件、源码、网页内容不会覆盖 Agent 系统指令
- [ ] 外部发送和破坏性动作必须审批
- [ ] 数据导出受权限控制并记录审计
- [ ] 日志未泄漏秘密或敏感原文
- [ ] 依赖和插件来源、版本及许可证已审查
- [ ] 备份和恢复策略已演练（适用时）
