# Definition of Done Checklist

- [ ] 对应 Feature Spec / Task 已更新
- [ ] 验收条件逐项验证
- [ ] 自动化测试真实运行并通过
- [ ] lint / typecheck / build 通过（项目适用项）
- [ ] 错误、加载、空状态和边界情况已处理
- [ ] 权限、审计和安全检查已完成
- [ ] 数据迁移/备份/回滚策略已验证（如适用）
- [ ] 完整 diff 已审查，无无关改动
- [ ] 用户文档、开发文档和 Agent 指令已更新
- [ ] ADR 和已知问题已更新
- [ ] 演示/验收步骤可重复
- [ ] 剩余风险和未完成项已明确记录
