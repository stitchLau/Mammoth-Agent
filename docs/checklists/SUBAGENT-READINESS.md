# SubAgent / AgentTeam 使用检查清单

## 委派前

- [ ] 任务目标能用一句话说明并可验收。
- [ ] 已选择正确角色定义。
- [ ] Fresh 子 Agent 的 prompt 包含完整背景，不依赖聊天上文。
- [ ] 已提供仓库路径、分支/Commit、输入文件。
- [ ] 已明确只读或精确写入范围。
- [ ] 已明确禁止事项和完成定义。
- [ ] 已判断委派收益是否高于上下文与协调成本。

## 并行前

- [ ] 子任务之间真正独立，或依赖关系已经表达。
- [ ] 不会并发修改同一文件、模块、迁移或公共契约。
- [ ] 如果并行编码，每个实现任务都有独立 Worktree/分支。
- [ ] 没有把 AgentTeam 任务板当作文件锁。
- [ ] 已确认当前 DSH 工具和 Profile 能力。

## 返回结果后

- [ ] 关键结论有代码路径、文档、行号、命令或版本证据。
- [ ] 事实、推断、假设和未知已区分。
- [ ] 子 Agent 没有超出写入授权。
- [ ] 冲突已回到原始证据核验。
- [ ] Lead 已形成综合结论，而不是原样拼接报告。
- [ ] 重要结论已进入 Spec、Task、ADR 或正式工作日志。
